Native dialog

The dialog tag gives a real modal for free: focus stays inside, Esc closes it, and the page behind is blocked.

Empty slots

Name, film, year and features are empty elements with ids. JavaScript fills them for whichever suit you click.

3D or photo

An iframe holds the Sketchfab model; two toggle buttons switch to the photo, with aria-pressed showing which is on.

The armor file is a single dialog element at the end of the body. Instead of thirteen pop-ups, there is one, and JavaScript fills it with the clicked suit’s data. Inside: a close button with an aria-label; the visual side with the big Roman numeral, a ring, the 3D viewer (a loading spinner, the iframe that shows the Sketchfab model, and the suit photo as a second view), a hint, the 3D/Photo toggle and a credit line for the model’s creator. The iframe’s referrerpolicy="origin" overrides the page’s no-referrer rule, because the 3D viewer needs to know which site embedded it before it will talk to sait.js. The other side has empty slots for the name, nickname, film, debut year, power source, description and feature list, plus previous and next buttons.
