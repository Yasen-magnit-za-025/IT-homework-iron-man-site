LINES 250–315 · NAVIGATION

A nav bar that reacts to scrolling

.nav {
  position: fixed; top: 0;
  transition: height .4s, background .4s;
}
.nav.is-scrolled {
  background: rgba(5,5,6,.78);
  backdrop-filter: blur(14px);
}
.nav.is-hidden { transform: translateY(-100%); }
.nav__progress {
  transform: scaleX(var(--p, 0));
}

Three states

Transparent at the top, frosted glass once you scroll (.is-scrolled), and tucked away while scrolling down (.is-hidden).

A progress bar

JavaScript sets --p from 0 to 1 as you scroll; the bar under the nav grows with scaleX.

The back‑to‑top button

A red circle in the corner that fades in after one screen of scrolling.

The nav is position: fixed so it stays at the top. Its height and background transition smoothly. When JavaScript adds is-scrolled it gets a dark translucent background with a blur behind it, the frosted-glass look. is-hidden slides it up out of view while you scroll down, and it comes back when you scroll up. The brand is the small reactor plus "Iron Man" with "Man" in red. Links are small Stark-font labels that turn bright on hover or when active. The progress bar is a gradient line scaled horizontally by --p. The toggle (hamburger) is hidden on desktop; its two lines rotate into an X when aria-expanded is true. The back-to-top button is fixed bottom-right, invisible until JavaScript adds is-visible, and turns gold on hover.
