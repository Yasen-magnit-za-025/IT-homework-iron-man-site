Part three covers the script in order. The pattern repeats everywhere: an init function finds its elements, adds event listeners, and either reacts to clicks and keys straight away or returns an update function that the shared scroll loop calls once per frame. JavaScript rarely moves things itself; it usually just sets a CSS variable or adds a class, and CSS does the animating.
