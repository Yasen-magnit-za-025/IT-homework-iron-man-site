Sticky pinning and flame thrusters

.hero { height: 260vh; }
.hero__pin {
  position: sticky; top: 0;
  height: 100svh; overflow: hidden;
}
.thruster {
  top: 97.5%; left: 32.5%;
  transform: translateX(-50%)
    scaleY(var(--flame));
}

Why 260vh

The section is 2.6 screens tall, but its sticky frame only 1. The extra 1.6 screens of scrolling play the take‑off.

Layers that move

Each layer’s transform reads --mx, --my and --depth, so the mouse moves near layers more than far ones.

Flames from a variable

The thrusters stretch with scaleY(var(--flame)). JavaScript only changes one number from 0 to 1.

Part 5 styles the hero. .hero is 260vh tall; .hero__pin is sticky with top 0 and exactly one screen tall, so it stays put while the extra height scrolls past. It clips its contents with overflow hidden and isolates its stacking. The background image is darkened and starts slightly zoomed so it can settle on load. The scrim is a gradient for text contrast. Each .hero__layer uses one transform built from CSS variables: --mx and --my come from the mouse, --depth differs per layer, and --sy comes from scrolling. The title uses the Stark font at up to 23vw with a silver gradient clipped to the text, and each word slides up from behind a mask. .hero__suit wraps the Mark III image. The thrusters are positioned under each boot (32.5% and 79% across) and drawn with radial gradients, flickering via a fast keyframe. The ground blast has three expanding rings. Finally, .hero.is-ready runs the entrance, and .hero__foot positions the tagline, intro, chips and the explore link.
