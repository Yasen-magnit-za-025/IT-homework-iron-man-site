Returning update()

Init functions return an update function. They don’t listen to scrolling themselves; the shared loop calls them.

A line at 60%

The rail fills up to an imaginary line 60% down the screen, and each chapter dot lights up as it crosses it.

Skip what’s off screen

Each update checks the element’s position first and returns early when it’s far away, saving work.

initParallax finds every element with data-parallax and, on each scroll frame, moves it by the distance between its centre and the screen’s centre times the factor. It skips anything more than 100px off screen. (Nothing currently uses data-parallax since the interlude became a pinned scene, so it is a harmless leftover.) initTimeline measures the timeline’s box with getBoundingClientRect, works out how much of it has passed an imaginary line 60% down the viewport, and writes that as --fill (0 to 1), which the CSS uses to scale the gold rail. It also adds is-lit to each chapter whose dot has crossed the line. Both return their update function instead of adding their own scroll listener, so all scroll work happens together once per frame.
