An IIFE wrapper

The whole file is a function that runs itself once. Its variables stay private and can’t clash with other scripts.

Tiny helpers

$ and $$ shorten querySelector, clamp keeps a number in range, and two flags check reduced motion and mouse.

Data, not markup

ARMORS lists 13 suits and MODELS their 3D files. The gallery and dialog are built from this one list.

Lines 1 to 5 are a header comment. Line 6 opens an arrow-function IIFE (Immediately Invoked Function Expression) that closes on the last line, so nothing leaks into the global scope. 'use strict' turns on stricter error checking. root is the html element. $ returns one element, $$ returns an array of all matches. clamp limits a value between a min and max. reduceMotion and canHover read the visitor’s settings once with matchMedia. heroThrust is a shared number the hero sets and the embers read. Lines 17 to 111 hold WIKI (the image host prefix) and ARMORS: thirteen objects with each suit’s mark, name, nickname, film, year, power source, colour tone, image path, description and four features. armorSrc builds the full image URL. Lines 113 to 132 are MODELS, the Sketchfab id, title and author of each 3D model, attached to each armor with forEach.
