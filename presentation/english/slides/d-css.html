Part two covers the stylesheet in order. It is split into numbered parts with comment headers, from 1 (tokens and base) to 20 (colour), plus the reduced-motion block at the very end. A good way to read CSS: find the selector (what it styles), then the property (what it changes). Many rules start with .js, which means "only when JavaScript is running", so the page never ends up hidden if a script fails.
