LINES 1–99 · TOKENS AND BASE

Design tokens: decide once, use everywhere

@font-face { font-family: "Stark";
  src: url("fonts/stark-bold.otf"); }
:root {
  --bg: #050506;
  --red: #c4161c;
  --gold: #d7a84a;
  --arc: #9be8ff;
  --f-display: "Stark", sans-serif;
  --ease-out: cubic-bezier(.16,1,.3,1);
}
/* used as */ color: var(--gold);

Fonts first

Three @font-face rules load the Stark font files from the fonts folder: regular, bold and hollow.

Variables on :root

Every colour, font and easing curve is a --variable. Changing --red once updates every red on the site.

A clean base

Box‑sizing, no default margins, smooth scrolling, a grain texture and a gold focus ring for keyboard users.

Line 10 paints the page background near-black before anything else loads, so there is no white flash. Lines 12 to 15 load the three Stark font files with @font-face. Lines 17 to 47 are the design tokens on :root: background shades, ink colours at different opacities, red, gold and arc-cyan, the four font stacks, two easing curves, the page gutter, the max width and the nav height. Everything else in the file refers to these with var(). The rest of part 1 is the base: box-sizing border-box on everything, smooth scrolling with room for the nav, body font and colour, a fixed SVG noise texture for film grain, the selection colour, resetting margins and list styles, and a visible gold focus outline. It also defines .sr-only for screen-reader-only text, the skip link that slides in on focus, and the .wrap and .section helpers that every section uses for width and spacing.
