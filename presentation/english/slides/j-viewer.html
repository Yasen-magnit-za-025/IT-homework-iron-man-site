Sketchfab’s viewer API

The iframe loads the model; the API lets the page talk to it and frame the whole suit in view.

Load only when needed

A model downloads only when its 3D view is shown, and it’s unloaded when the dialog closes to free the graphics card.

Never stuck loading

A token cancels stale loads, and timers make sure the spinner always clears, even on a slow connection.

initViewer controls the 3D panel in the armor dialog. options turns on autostart, a transparent background, a slow auto-spin and hides the viewer’s extra buttons (some of those only take effect for paid Sketchfab accounts). loadModel increases loadToken, so a model that finishes loading after you have already switched suits is ignored. If the Sketchfab API script is missing it falls back to a plain iframe embed. With the API, once the viewer is ready it calls focusOnVisibleGeometries (or recenterCamera) to frame the whole model, then moves the camera 20% closer on desktop or 5% on narrow phones. setMode switches between the 3D model and the photo and only loads the model when 3D is shown. load() fills the credit line and button labels ("3D bust", "3D helmet"), and stop() unloads the iframe when the dialog closes.
