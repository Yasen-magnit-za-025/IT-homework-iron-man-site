An arc reactor drawn with pure CSS

.reactor {
  --s: 64px;
  width: var(--s); border-radius: 50%;
  background: radial-gradient(…);
}
.reactor::before {
  background: repeating-conic-gradient(…);
  animation: spin 24s linear infinite;
}
.reactor::after { animation: core 3.2s… }

One element, four layers

The circle, the copper coil ring (::before), the pulsing core (::after) and a dashed inner ring (the i tag).

Sized by one variable

--s sets the size, and the glow and borders scale from it. The same reactor is the logo, the boot screen and the tech core.

A boot failsafe

The boot screen hides itself after 4 seconds with a CSS animation, even if the script never finishes.

Part 3 builds the arc reactor from a single element and no images. The element is a circle with a radial gradient for the glowing centre and a box-shadow for the outer glow. ::before is the ring of copper coil segments: a repeating-conic-gradient masked into a ring and spun slowly. ::after is the bright core, pulsing with the "core" keyframes. The i element inside is the dashed inner ring, spinning the other way. Every size is calculated from --s, so the same class works at 26px in the nav, 74px on the boot screen and over 200px in the tech section. The boot screen is a full-screen overlay with the reactor, text and a loading bar. It disappears when JavaScript removes is-booting from the html element, and as a safety net an animation hides it after 4 seconds no matter what.
