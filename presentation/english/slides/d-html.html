The page’s structure: what exists, in what order, and what it means. No styling, no behaviour, just content and labels.

883 lines · 10 slides · read top to bottom

Part one covers the HTML file in order, from the head at line 1 to the armor dialog at the end. Every slide names its line range. A useful way to read HTML is to ask, for each tag: what is this, and who is it for? Some tags are for visitors (headings, images), some for screen readers (aria labels), and some are hooks for the CSS and JavaScript (classes, ids and data attributes).
