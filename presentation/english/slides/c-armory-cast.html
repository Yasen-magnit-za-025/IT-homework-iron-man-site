Scrolling cards and growing panels

  display: flex; overflow-x: auto;
  scroll-snap-type: x mandatory;
}
.suit { --tone: 196, 22, 28; }
.player { flex: 1 1 0; }

.player__photo {
  transition: filter .8s, width .8s;

A snapping gallery

The hall is a sideways‑scrolling flex row; scroll‑snap makes each card stop neatly at the edge.

One colour per suit

Each card sets --tone as an RGB triplet, so its glow, border and stripe all use that suit’s colour.

Flex‑grow panels

All cast panels share the space equally; the active one grows to 4.2 shares and the photo slides to half width.

The Armory part styles the hall as a horizontally scrolling flex row with scroll snapping and a hidden scrollbar; while dragging, snapping turns off. Each .suit card has a --tone variable written as "R, G, B", so rgba(var(--tone), .3) can give any transparency of that suit’s colour. The card shows a big outlined Roman numeral, the suit image, a 3D badge and the labels, with a bottom stripe that grows on hover. The progress bar under the hall is scaled by --hp. The Cast part is a flex row of five panels, each flex: 1, with the active one at flex-grow 4.2, so it widens smoothly. Inactive photos are filtered (now a red duotone). The vertical name tab is rotated text. The body with the still, role, name and description fades in only on the active panel. Under 960px the row becomes a column of short bars, with the active one tall.
