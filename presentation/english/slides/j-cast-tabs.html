Cast panels

Hover, click, focus or Enter makes a panel active. Only one panel has .is-active at a time.

A reusable function

initTabs works for any tablist. The villains and the tech schematic both use it, each passing its own onChange.

Keyboard support

Arrow keys move to the next or previous tab, Home and End jump to the first and last, as tab widgets should.

initCast gives each cast panel listeners for pointerenter (mouse only), click, focus and Enter or Space, all calling activate, which toggles is-active so only one panel is open. initTabs is a general tab controller: select() updates aria-selected, puts only the chosen tab in the tab order, shows its panel and hides the rest, then calls onChange so each user can react. The keydown handler moves with arrow keys and Home and End, and scrolls a horizontal tab list to keep the focused tab visible. preloadNear starts loading a section’s lazy images 900px before it scrolls into view. initVillains sets the tablist to vertical, uses onChange to fade in the matching background image, and preloads the backdrops so switching never shows an empty frame.
