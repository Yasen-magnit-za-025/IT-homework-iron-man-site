Viewport and title

Lines 4–10 set the character set, phone scaling, the tab title, a description and an arc‑reactor favicon drawn as inline SVG.

No referrer

The wiki that hosts the images blocks requests from other sites, so line 7 tells the browser to send no referrer at all.

Linking the files

Lines 11–20 preload fonts, link sait.css, flag that JS is running, then load sait.js with defer so it runs after the page is built.

Line 1 declares a modern HTML document. Line 2 opens the html element with the English language and a no-js class. Lines 4 and 5 set UTF-8 text and make phones use their real width instead of zooming out. Line 7 is the no-referrer rule: the image host refuses requests that say which site they came from. Lines 8 to 10 are the description, the browser bar colour and the page title. Line 11 is the favicon, an SVG drawing of the arc reactor written straight into the link. Lines 12 to 14 open early connections to Google Fonts and the image host so they load faster. Line 15 loads the Exo 2 font. Line 16 links the stylesheet. Line 17 is a one-line script that swaps no-js for "js is-booting": CSS uses that to hide things only when JavaScript is available, and to show the boot screen. Line 19 loads Sketchfab’s viewer API for the 3D models, and line 20 loads sait.js with defer, so the script waits until all the HTML is parsed.
