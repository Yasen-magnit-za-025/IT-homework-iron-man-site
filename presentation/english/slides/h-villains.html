ARIA roles

role="tablist", "tab" and "tabpanel" tell screen readers this is a tab set, not just a pile of buttons.

One tab in the order

Only the selected tab has tabindex="0"; the rest are −1, so Tab skips them and the arrow keys move between them.

hidden panels

Every file but the first has the hidden attribute. JavaScript removes it from the panel whose tab is chosen.

The Villains section has six background images stacked at the top, one per villain, each tagged with data-rogue so JavaScript can fade in the right one. The index is a tablist of six buttons. Each button says which panel it controls (aria-controls) and whether it is selected (aria-selected). Only the selected one is in the tab order; the arrow keys move between the others, which is how proper tab widgets behave. The panels are article elements with role="tabpanel", aria-labelledby pointing back at their tab, and the hidden attribute on all but the first. Each panel has a meta line (file number, film, actor), the villain’s name as an h3 with the alias in small, a description, and a "Connection to Tony Stark" box.
