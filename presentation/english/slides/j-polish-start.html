The start list

The last lines call every init once. Those that return an update are passed to the scroll loop in one array.

initDepth moves story images, the villain backdrop and the footer image by a small, clamped amount against the scroll using the translate property. initNavIndicator adds one bar to the desktop menu and moves it with transform to the hovered link or, when nothing is hovered, to the active one; a MutationObserver notices when the scroll-spy changes the active link. initFilmCover sets --cover on the Film section as the Story section’s top rises through the screen. Lines 1457 to 1476 are the start-up list: plain init functions that only set up listeners run first, then initScrollLoop receives the update functions returned by the scroll-driven inits. The final line closes the IIFE that opened on line 6.
