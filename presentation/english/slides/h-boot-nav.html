Skip link

Keyboard users can jump past the menu straight to the first section. It only shows when focused.

Boot screen

A spinning reactor and “initializing” text cover the page while fonts and the hero image load.

Menu

Links point at section ids (#film, #story…). The toggle button opens the phone menu and reports its state with aria‑expanded.

Line 23 is the skip link, a standard accessibility feature for keyboard users. Lines 25 to 30 are the boot screen: an arc reactor, the text "Stark Industries // initializing" and a loading bar. It is hidden from screen readers with aria-hidden because it is only decoration. Lines 32 to 56 are the navigation. The brand link goes back to the top (#top). The nav element holds seven links, one per section, each using a hash link so the browser scrolls to the matching id. The "Suit up" button links to the armory. The toggle button is the hamburger for phones: aria-expanded tells screen readers whether the menu is open, and aria-controls names the menu it opens. The last span is the thin progress bar under the nav that fills as you scroll.
