Filled by JavaScript

The armory gallery starts empty: the 13 suit cards are built from a data list in sait.js, so the HTML stays short.

A noscript fallback

If JavaScript is off, a message explains why the gallery is missing instead of leaving a blank gap.

Focusable panels

Each cast article has tabindex="0", so keyboard users can tab to it and open it like a mouse user hovering.

The Armory section has its heading, the counter (01 / 13) and two arrow buttons with aria-labels, since they only show an icon. The gallery itself, div id "hall", is empty in the HTML: JavaScript builds the thirteen suit cards from the ARMORS data, which avoids repeating thirteen nearly identical blocks of markup. A noscript message covers visitors without JavaScript. Under it are the progress bar and a hint line. The Cast section has five article elements, one per actor. Each holds the actor’s portrait, a number, a vertical name tab, and a body with a film still, the role, the actor’s name as an h3 and a short description. The first one starts with the is-active class. tabindex="0" makes each panel reachable by keyboard, and aria-label gives each panel a clear name.
