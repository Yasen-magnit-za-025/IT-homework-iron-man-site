The Tech section is a holographic schematic. schematic__stage is a square holding: an empty svg where JavaScript draws the connector lines, three spinning rings, a radar sweep, a shockwave ring, the arc reactor core and a readout. The seven system buttons are tabs; each has a style="--i:N" number that the CSS uses with cos() and sin() to place it around the circle. The seven panels are articles with role="tabpanel", each with a code label, a heading, a description and a specs list. Each panel has its own control: the arc reactor slider, two AI chat boxes with command buttons, the repulsor hold button, the HUD scan button, workshop station buttons and the flight throttle slider. Every slider has a label element, so its purpose is announced.
