Части, използвани навсякъде

.js [data-reveal] {
  opacity: 0;
  transform: translateY(32px);
  filter: blur(8px);
  transition: opacity 1s, transform 1.1s;
  transition-delay: var(--d, 0s);
}
.js [data-reveal].is-in {
  opacity: 1; transform: none;
  filter: none;
}

Класове за многократна употреба

.eyebrow, .display, .btn, .round-btn и .chip се стилизират веднъж тук и се ползват във всяка секция.

Скрито само с JS

Правилата за появяване започват с .js, така че ако скриптът не тръгне, нищо не остава невидимо.

Превключвателят .is-in

Елементите започват избледнели, свалени и размазани. JavaScript добавя .is-in, когато влязат в екрана, и CSS ги анимира.

Част 2 определя частите, които всички секции споделят. .eyebrow е малкият етикет с номер в рамка. .display е огромното заглавие на секция, а .display em е контурната втора дума, направена с прозрачна запълка и -webkit-text-stroke. .section-head подрежда блок със заглавие. .btn е бутонът с отрязан ъгъл, направен с clip-path, със състояния при посочване и натискане; .round-btn е кръглият бутон със стрелка; .chips и .chip са кръглите значки с факти в началния екран. После идва системата за появяване: всичко с data-reveal започва скрито, изместено надолу и размазано, но само когато елементът html има клас js. Варианти: „left“ и „right“ влизат отстрани, „wipe“ се открива с clip-path, а „mask“ плъзга текста нагоре иззад ръб с overflow:hidden. Когато JavaScript добави is-in, всеки вариант преминава към крайното си, нормално състояние. --d е закъснение, зададено от JavaScript, за да се разредят групите.
