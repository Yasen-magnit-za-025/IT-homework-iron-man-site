Меню, което реагира на скрола

.nav {
  position: fixed; top: 0;
  transition: height .4s, background .4s;
}
.nav.is-scrolled {
  background: rgba(5,5,6,.78);
  backdrop-filter: blur(14px);
}
.nav.is-hidden { transform: translateY(-100%); }
.nav__progress {
  transform: scaleX(var(--p, 0));
}

Три състояния

Прозрачно най-горе, матово стъкло след скрол (.is-scrolled) и прибрано, докато скролваш надолу (.is-hidden).

Лента за прогрес

JavaScript задава --p от 0 до 1 при скролване; лентата под менюто расте със scaleX.

Бутонът „нагоре“

Червен кръг в ъгъла, който се появява плавно след един екран скрол.

Менюто е с position: fixed, за да остава най-горе. Височината и фонът му се сменят плавно. Когато JavaScript добави is-scrolled, то получава тъмен полупрозрачен фон с размазване отзад – ефектът на матово стъкло. is-hidden го плъзга нагоре извън екрана, докато скролваш надолу, и то се връща, когато скролваш нагоре. Марката е малкият реактор плюс „Iron Man“, с „Man“ в червено. Връзките са малки етикети с шрифта Stark, които светват при посочване или когато са активни. Лентата за прогрес е градиентна линия, мащабирана хоризонтално с --p. Бутонът за превключване (хамбургерът) е скрит на десктоп; двете му линии се завъртат в X, когато aria-expanded е true. Бутонът „нагоре“ е фиксиран долу вдясно, невидим, докато JavaScript не добави is-visible, и става златен при посочване.
