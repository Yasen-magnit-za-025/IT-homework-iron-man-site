Дъгов реактор, нарисуван само с CSS

.reactor {
  --s: 64px;
  width: var(--s); border-radius: 50%;
  background: radial-gradient(…);
}
.reactor::before {
  background: repeating-conic-gradient(…);
  animation: spin 24s linear infinite;
}
.reactor::after { animation: core 3.2s… }

Един елемент, четири слоя

Кръгът, медният пръстен с намотки (::before), пулсиращото ядро (::after) и пунктиран вътрешен пръстен (тагът i).

Размер от една променлива

--s задава размера, а сиянието и рамките следват от нея. Същият реактор е логото, екранът за зареждане и ядрото в Tech.

Защита при зареждане

Екранът за зареждане се скрива сам след 4 секунди с CSS анимация, дори ако скриптът не завърши.

Част 3 изгражда дъговия реактор от един елемент без снимки. Елементът е кръг с радиален градиент за светещия център и box-shadow за външното сияние. ::before е пръстенът от медни намотки: repeating-conic-gradient, маскиран във формата на пръстен и бавно въртящ се. ::after е яркото ядро, пулсиращо с keyframes „core“. Елементът i вътре е пунктираният вътрешен пръстен, който се върти в обратна посока. Всеки размер се изчислява от --s, така че един и същ клас работи с 26px в менюто, 74px на екрана за зареждане и над 200px в секцията Tech. Екранът за зареждане е слой на цял екран с реактора, текст и лента за зареждане. Изчезва, когато JavaScript махне is-booting от елемента html, а като предпазна мрежа анимация го скрива след 4 секунди каквото и да стане.
